Not a dashboard

It sits in the panel.
The clock stays put.

Eave is a standalone top-center overlay inside GNOME Shell — not the date menu, not a Hyprland layer-shell widget, not an Electron window. Mutter has no wlr-layer-shell, so the only way the island can live in the Fedora Wayland panel is in-process.

Right-click the idle notch for the calendar. Notifications stay in GNOME’s native banners. Other MPRIS panel widgets hide so they do not sit behind the pill.

Media, compact then expanded

Album art and a six-bar waveform while it plays. Hover shows a filled play/pause that actually toggles. Click opens a compact 344×84 now-playing panel that hangs from the top bar: marquee title, art-tinted waves, capsule scrubber, transport.

Plug in and the island becomes a short pill with the percentage — then it recedes. Bluetooth does the same with the device name. Privacy (mic, camera, screen recording) stays as a compact activity while in use.

Volume, brightness, mute

A thick-capsule HUD in the island instead of the stock GNOME OSD. Turn takeover off in settings if you want the original overlay back. Alignment sliders apply live — no logout.

Install on Fedora

Target: Fedora 44 (GNOME 50), also GNOME 49 and 51. Existing installs keep working — the extension UUID is still dynamic-island@xaminezh.xyz.

  1. Install the tools

    sudo dnf install gnome-extensions-app glib2 make zip

  2. Clone and install

    git clone https://github.com/XaMiNeZH/dynamic-island-linux.git
cd dynamic-island-linux
./install.sh

  3. Try it without logging out

    Wayland cannot reload extension code inside the running Shell. Open a nested GNOME window instead:

    sudo dnf install mutter-devkit   # once, GNOME 49+
./tools/try.sh

    If the island is missing in that window:

    gnome-extensions enable dynamic-island@xaminezh.xyz

Settings live at Extensions → Eave → Settings, or gnome-extensions prefs dynamic-island@xaminezh.xyz.
